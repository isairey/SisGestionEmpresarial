# 🏢 Sistema de Gestión Empresarial (ERP) — Pascal

Aplicación desarrollada en **Pascal** para la administración de procesos empresariales, permitiendo gestionar clientes, productos, ventas y operaciones básicas de negocio desde una interfaz de escritorio.

---

## 🚀 Descripción

El **Sistema de Gestión Empresarial en Pascal** es una solución enfocada en la organización y control de información dentro de una empresa.

Está diseñado como una aplicación ligera que permite manejar operaciones esenciales como inventario, ventas y registros administrativos, siendo ideal para fines educativos o sistemas locales.

---

## 🎯 Características principales

* 👤 **Gestión de clientes**

  * Registro y consulta de clientes
  * Edición y eliminación de datos

* 📦 **Gestión de productos**

  * Alta, baja y modificación de productos
  * Control básico de inventario

* 🧾 **Ventas**

  * Registro de ventas
  * Cálculo automático de totales

* 📊 **Reportes**

  * Listado de clientes
  * Reportes de productos y ventas

* 💾 **Persistencia de datos**

  * Uso de archivos locales (TXT / DAT)

* 🖥️ **Interfaz**

  * Aplicación de consola o interfaz básica (según implementación)

---

## 🛠️ Tecnologías utilizadas

* 🧠 Pascal (Free Pascal / Turbo Pascal)
* 💾 Manejo de archivos (File Handling)
* 🖥️ Consola / interfaz básica

## ⚙️ Instalación y ejecución

1. Instalar compilador Pascal:

* Free Pascal (recomendado)

2. Clonar el repositorio:

```bash id="p7x3le"
git clone https://github.com/isairey/SisGestionEmpresarial.git
```

3. Acceder al proyecto:

```bash id="n8c2dr"
cd SisGestionEmpresarial
```

4. Compilar el programa:

```bash id="v5k1yt"
fpc main.pas
```

5. Ejecutar:

```bash id="b2w6os"
./main
```
